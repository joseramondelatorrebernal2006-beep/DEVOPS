# DevOps: principios, fases, CI/CD y automatización

## 1. Principios de DevOps

DevOps combina desarrollo (*Development*) y operaciones (*Operations*)
para entregar software de forma rápida, fiable y segura.

-   **Colaboración:** desarrollo y operaciones comparten objetivos y
    responsabilidades.
-   **Automatización:** reduce tareas manuales y errores.
-   **Integración continua (CI):** integra cambios de código y ejecuta
    pruebas frecuentes.
-   **Entrega y despliegue continuos (CD):** prepara o publica versiones
    de forma automatizada.
-   **Monitorización:** detecta errores y supervisa el rendimiento.
-   **Mejora continua:** aprende de los resultados y optimiza los
    procesos.
-   **Seguridad (DevSecOps):** incorpora controles de seguridad durante
    todo el ciclo.
