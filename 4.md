## 4. Automatización de procesos

La automatización usa herramientas y scripts para ejecutar tareas
repetitivas con menos intervención manual.

**Ejemplos:** - Ejecutar pruebas cuando se sube código. - Construir una
imagen Docker. - Analizar calidad y vulnerabilidades. - Desplegar una
nueva versión. - Crear y configurar servidores. - Generar alertas ante
errores.

**Flujo CI/CD típico:**

`Subir código → Ejecutar pruebas → Construir artefacto → Publicar → Desplegar → Monitorizar`

Si una prueba falla, el pipeline puede detenerse para evitar que una
versión defectuosa llegue a producción.

## 5. Beneficios

-   Entregas más rápidas y frecuentes.
-   Menos errores manuales.
-   Procesos repetibles y trazables.
-   Mejor colaboración entre equipos.
-   Mayor control de calidad y seguridad.

**En resumen:** DevOps es una cultura y un conjunto de prácticas que
conectan desarrollo y operaciones. La automatización y CI/CD ayudan a
entregar software de forma eficiente, segura y fiable.
