## 3. Herramientas CI/CD

CI/CD automatiza la integración, validación y publicación del software.

  Herramienta                              Uso principal
  ---------------------------------------- -----------------------------------------
  Git y GitHub                             Control de versiones y colaboración
  GitHub Actions, Jenkins o GitLab CI/CD   Automatizar pipelines
  pytest o JUnit                           Ejecutar pruebas
  SonarQube                                Analizar la calidad del código
  Docker                                   Empaquetar aplicaciones en contenedores
  Kubernetes                               Gestionar contenedores
  Terraform y Ansible                      Crear y configurar infraestructura
  Prometheus y Grafana                     Monitorizar sistemas

**Diferencia importante:** - **Entrega continua:** el software queda
preparado para publicarse; puede requerir aprobación manual. -
**Despliegue continuo:** los cambios validados se publican
automáticamente.
